# Cinema Schedule Planner

This repository is organized by **process domains** and **data lifecycle**.

## Architecture

- `apps/scraping/`: data collection scripts (Renoir, Golem, FilmAffinity).
- `apps/pipelines/`: consolidation and transformation workflows.
- `apps/services/`: HTTP APIs and service processes.
- `apps/frontend/`: browser UI assets and frontend server helper.
- `data/raw/`: source data directly collected from providers.
- `data/interim/`: intermediate outputs between scraping and presentation.
  - `data/interim/cinema_sessions/archive/{renoir,golem}` stores historical backup snapshots.
- `data/processed/`: curated datasets for downstream use.
- `data/outputs/`: final workflow outputs and exports.

## How to Run Each Workflow

### 1) Scraping workflows

- **Run all scrapers**
  - Command: `python apps/scraping/run_scraping_workflow.py`
  - Inputs: provider websites
  - Outputs:
    - `data/interim/cinema_sessions/*.csv`
    - `data/interim/cinema_sessions/latest.json`
    - archives moved to `data/interim/cinema_sessions/archive/{renoir,golem}`
    - `data/raw/film_affinity/upcoming_releases.csv`

- **Run individual scrapers**
  - Renoir: `python apps/scraping/extract_renoir_showtimes.py`
  - Golem: `python apps/scraping/extract_golem_showtimes.py`
  - FilmAffinity upcoming releases: `python apps/scraping/scrape_film_affinity_upcoming_releases.py`

### 2) Pipeline workflow

- **Build movies-to-watch aggregate**
  - Command: `python apps/pipelines/build_movies_to_watch.py`
  - Inputs: `data/interim/cinema_sessions/*.csv`
  - Outputs: terminal analysis/report generated by the script

### 3) Service workflow

- **Seat map + upcoming releases service**
  - Command: `python apps/services/seat_map_service.py --host 127.0.0.1 --port 8787`
  - Inputs:
    - ticket URL query parameters
    - `data/raw/film_affinity/upcoming_releases.csv`
  - Outputs: JSON responses from HTTP API endpoints

### 4) Frontend workflow

- **Serve frontend locally**
  - Command: `python apps/frontend/serve_frontend.py`
  - Open: `http://127.0.0.1:8080/apps/frontend/index.html`
  - Inputs:
    - `data/interim/cinema_sessions/latest.json`
    - `data/interim/cinema_sessions/*.csv`
    - service endpoint from `apps/services/seat_map_service.py`

## Compatibility shims

Legacy numbered scripts remain at repository root as wrappers to minimize breakage:

- `1_CinesDataExtractor_Renoir.py`
- `1_CinesDataExtractor_Golem.py`
- `2_MoviesToWatch.py`
- `3_PillalasSeatMapService.py`
- `X_FilmAffinityUpcomingReleasesScraper.py`

These wrappers forward execution to the new process-oriented paths.
